# DaF kompakt مبسّط

تطبيق لتعلم الألمانية: الدروس 1 إلى 5 من كتاب DaF kompakt neu A1، مبسّطة بالعربية في 20 يوماً (ساعة لكل يوم).

**افتح التطبيق:** https://bghzmouhsine.github.io/Daf-kompakt/

- نطق ألماني مسجّل لكل كلمة وجملة، بسرعة عادية وبطيئة
- مشغّل الدرس: مراجعة، مفردات، قاعدة، تمارين، جملة اليوم
- بطاقات مراجعة ذكية ووضع استماع
- يُثبَّت على الهاتف من Chrome ويعمل بدون إنترنت

التطبيق ملخص دراسي شخصي ولا يغني عن الكتاب الأصلي.

## Deutschstunde A1 — التطبيق الكامل (الدروس 1 إلى 8)

**افتح التطبيق:** https://bghzmouhsine.github.io/Daf-kompakt/app/

- 8 دروس × 3 وحدات، شرح بالعربية، حوالي 1000 كلمة مع der/die/das والجمع والأمثلة
- تمارين تفاعلية مع تصحيح وشرح الأخطاء، 24 حوارًا بثلاثة مستويات
- نطق واستماع، تقييم النطق بالميكروفون في Chrome، الأصوات الصعبة للمتحدثين بالعربية
- مراجعة متباعدة، سجل يومي وإحصاءات، تذكير يومي، تدريب Start Deutsch 1
- يُثبَّت على الهاتف من Chrome (القائمة ⋮ ← تثبيت التطبيق) ويعمل بدون إنترنت
