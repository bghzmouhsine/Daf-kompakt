# Deutschstunde — مدرّسك الألماني الشخصي (A1 + A2)

**افتح التطبيق:** https://bghzmouhsine.github.io/Daf-kompakt/

تطبيق ويب كامل (PWA) لتعلّم الألمانية للناطقين بالعربية: يُثبَّت على الهاتف كتطبيق مستقل (Chrome ← ⋮ ← «تثبيت التطبيق») ويعمل بدون إنترنت.

## المحتوى
- **A1 (الدروس 1–8):** حسب ترتيب كتاب DaF kompakt neu A1 — شرح بالعربية، قرابة 950 كلمة.
- **A2 (الدروس 9–18):** محتوى أصلي حسب منهج A2 (Goethe/ÖSD): الصحة، العمل، السكن، الأعياد، السفر، الإعلام، الطبخ، التعليم، البيئة، الحياة في ألمانيا — قرابة 850 كلمة جديدة.
- 54 وحدة، في كل وحدة: الشرح والقواعد، المفردات (der/die/das + الجمع + أمثلة + صور)، التمارين، حوار تفاعلي بثلاثة مستويات، الاستماع والإملاء، النطق، اختبار.

## الميزات
- صوت ألماني طبيعي مسجّل (صوت رجل وصوت امرأة) لكل الكلمات والجمل والحوارات، تشغيل بطيء، وتنزيل للاستعمال دون إنترنت.
- تصحيح فوري مع شرح الخطأ بالعربية، وتتبّع الأخطاء المتكررة وإعادة التدريب عليها.
- مراجعة متباعدة للكلمات، مستوى متكيّف، نقاط القوة والضعف.
- XP ومستويات ومهام يومية وتجميد السلسلة، هدف وتقرير أسبوعي.
- اختبار تحديد المستوى، امتحان تجريبي Start Deutsch 1 كامل بالوقت.
- مدرّس ذكي (محادثة حرة، تصحيح الكتابة، تقييم نطق متقدّم من التسجيل) بمفتاح Gemini مجاني أو Claude.
- مزامنة التقدّم بين الأجهزة عبر GitHub Gist (اختياري).
- خطة يومية بموعدك، تذكير بالإشعارات وبتقويم Google.
